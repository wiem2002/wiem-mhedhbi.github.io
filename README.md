# Wiem Mhedhbi Portfolio

Static one-page portfolio for **Wiem Mhedhbi**, focused on Data Science, AI Engineering, Machine Learning, Deep Learning, NLP, data visualization, and applied AI projects.

## Overview

This portfolio presents:

- A recruiter-focused hero section with project and contact CTAs.
- About / AI profile section.
- Filterable technical skills stack.
- Applied AI project case studies with modal details.
- Experience and internship timeline.
- Certifications showcase.
- Contact command center with real email, phone, GitHub, and LinkedIn links.

## How To Open

No build step is required.

Open `index.html` directly in a browser:

```text
index.html
```

The site is static and frontend-only. It does not use a backend, database, package manager, or build tooling.

## Technologies

- HTML5
- CSS3
- JavaScript
- Tailwind CDN runtime
- Font Awesome
- Google Fonts

## Main Features

- Responsive dark AI/Data portfolio design.
- Accessible navigation, skip link, semantic sections, and focus states.
- Reduced-motion support.
- Project case-study modal powered by local JavaScript data.
- Functional skills filters.
- Mobile-friendly layout across hero, about, skills, projects, experience, certifications, and contact sections.

## Notes

- The project uses public CDNs for Tailwind, Google Fonts, and Font Awesome.
- All project data is local and static.
- Contact links are real `mailto`, `tel`, GitHub, and LinkedIn links.
- The portfolio can be hosted on any static hosting service.
